# # Apple Device Management System

A database project developed using MySQL to manage Apple devices and their related information.

## Project Overview

This project includes tables for devices, specifications, operating systems, processors, storage options, colors, inventory, suppliers, customers, and orders.

## Key Features

- Relational database design using primary and foreign keys.
- Device specifications and storage options.
- Inventory tracking across store locations.
- Supplier and customer order management.
- SQL views for device details, inventory status, supplier order summaries, customer orders, and device colors.

## Technologies Used

- MySQL
- SQL
- JOINs, aggregate functions, subqueries, and views

## Project Status

Educational database project. The database schema and sample data are included in the SQL script.

## How to Run

1. Open the `apple_device_management.sql` file.
2. Copy the SQL script into a MySQL-compatible environment.
3. Execute the script in order to create the tables, insert sample data, and create the views.
